How can I connect this to my exiting gardeo app
Great question! Connecting this mobile app to your existing Gardeo backend is straightforward. Here's what you need to do:

The one thing you need to set: an environment variable called EXPO_PUBLIC_API_URL with the base URL of your existing Gardeo backend API.

For example, if your backend runs at https://api.gardeo.co.uk, you'd set:

EXPO_PUBLIC_API_URL=https://api.gardeo.co.uk
Once that's set, the app will automatically switch from demo mode to calling your real API.

Your backend needs these API endpoints (the app expects them):

Method	Endpoint	Purpose
POST	/auth/login	Login (email + password), returns { token, user }
GET	/officers/me	Get logged-in officer's profile
PATCH	/officers/me	Update profile details
GET	/officers/me/shifts	Get officer's shifts
GET	/shifts/:id	Get single shift details
POST	/shifts/:id/book-on	Book on to a shift
POST	/shifts/:id/book-off	Book off from a shift
POST	/shifts/:id/ops-check	Submit operational check
GET	/officers/me/documents	Get compliance documents
GET	/officers/me/payslips	Get payslips
GET	/officers/me/messages	Get messages
POST	/officers/me/messages	Send a message
GET	/officers/me/notifications	Get notifications
The app uses Bearer token authentication — after login, the token is sent in the Authorization header on every request.
